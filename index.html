1. Overview & Single Purpose

EMC2ad is an internal enterprise security extension designed exclusively to protect user profile workspaces on shared and corporate computers via local PIN/password authentication, preventing unauthorized workspace modifications.

2. Data Collection and Usage

EMC2ad - Profile Security strictly respects user privacy. We comply fully with the Google Chrome Web Store Developer Program Policies, including the Limited Use policy.

  • No Personal Data Collection: We do NOT collect, harvest, monitor, or transmit any personally identifiable information (PII).
  • No Browsing History Tracking: We do NOT monitor, record, store, or sell browsing habits, page visits, search queries, or web interactions.
  • No External Server Communication: The extension does not connect to any third-party telemetry, analytical platforms, or external servers. All operations execute strictly on your device.

3. Local Storage and Credentials Security

To provide password protection and remember lock configurations across browser sessions, the extension makes use of Chrome's native chrome.storage.local API:

Local Security Guarantee: All verification credentials (such as PINs or passwords) are securely hashed using client-side cryptographic hashing (SHA-256) prior to being saved in local storage. Plaintext passwords are never stored or exposed.

4. Host Permissions (<all_urls>) Justification

The extension requests host permission for <all_urls> for one single and transparent purpose:

  • To dynamically inject a local, client-side visual overlay (lock screen) over active browser tabs whenever the user or system triggers profile protection mode.
  • This overlay prevents unauthorized view and interaction with confidential corporate tabs until the valid PIN is verified. No web page contents or form inputs are ever captured or read.
